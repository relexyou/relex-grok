# Positioning — Relex × Grok

**Relex doesn't replace Grok. It helps you use Grok end-to-end.**

Lawyers already use Grok. Confidential client data, firm know-how, payments, and
client intake are the missing layer. Relex is that layer — with cryptographic
PII sealing and an MCP guard so the model never receives plaintext client
identities or documents.
